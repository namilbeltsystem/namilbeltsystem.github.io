# Habasit English (Original) Technical PDFs

This directory holds the **original Habasit English-language** catalog pages, kept
separate from the fully-translated Korean editions in `../korean/`.

## Why split English / Korean

The earlier `docs/korean/*-kr.pdf` files mixed a Korean cover page with the original
English body, so the content was never fully Korean. Each title is now split into two
clean files:

- `docs/korean/<name>-kr.pdf`  — fully translated Korean edition (real Korean text layer)
- `docs/english/<name>-en.pdf` — the original Habasit English document (unmodified body)
